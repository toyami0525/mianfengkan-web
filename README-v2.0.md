# 眠楓館 v2.0

更新類型：系統更新

## 本版新增
- 後台「網站設定」可直接修改店名、地址、Discord、營業時間與營業狀態。
- 後台可直接修改首頁標語與服務摘要。
- 新增「規章管理」：新增、刪除、排序及編輯規章。
- 前台首頁與來館須知會自動讀取 Supabase 最新設定。

## 更新步驟
1. 在 Supabase SQL Editor 執行 `supabase/v2.0-site-settings-rules.sql`。
2. 將本專案內容覆蓋到 GitHub。
3. Commit / Push，等待 Vercel 部署。
4. 重新登入 `/admin`，即可看到「規章管理」與可編輯的「網站設定」。
